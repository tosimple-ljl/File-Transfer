# 基于 Qt 的 Socket 文件传输工具

课程作业：使用 Qt 6（C++）实现基于 TCP Socket 的文件传输工具，支持文本/图片文件在客户端与服务端之间可靠传输。

## 功能特性

- **基础通信**：`QTcpServer` 监听 / `QTcpSocket` 连接，支持多客户端接入
- **文件传输**：文本（.txt 等）与图片（.png/.jpg/.bmp 等）二进制完整传输，中文文件名不乱码
- **自定义协议头**：`消息类型(4B) + 文件名长度(4B) + 文件名 + 文件大小(8B) + 数据`，接收端状态机组包，彻底处理 TCP 粘包/半包
- **流水线发送**：`write + bytesWritten` 信号驱动，每次只发 64KB，大文件不占过多内存
- **拖拽收发**：拖文件进窗口/拖拽接收区即发送；拖拽悬停高亮反馈
- **事件处理**：同时体现虚函数重写（`dragEnterEvent`/`dropEvent`）与事件过滤器（`eventFilter`）
- **进度条与日志**：发送/接收双进度条（`QProgressBar`），带时间戳的传输日志
- **跨窗口通信**：设置对话框通过自定义信号 `settingsConfirmed` 向主窗口传参（IP/端口/保存目录）
- **QSS 美化 + 资源系统**：圆角按钮悬停变色、深色日志区、渐变进度条；图标经 `.qrc` 引入
- **错误处理**：连接失败、断开、文件打不开、写盘失败均有状态栏/弹窗提示，不崩溃

## 工程结构

```
FileTransferTool.pro        顶层 SUBDIRS 工程
├── common/                 公共代码（两端共用）
│   ├── packet.h/.cpp             协议定义与封包
│   ├── file_sender.h/.cpp        流水线发送器
│   ├── file_receiver.h/.cpp      状态机组包接收器
│   ├── transfer_manager.h/.cpp   会话管理（socket+收发器绑定）
│   ├── settingsdialog.*          设置对话框（.ui + 跨窗口信号）
│   ├── icons/                    图标（gen_icons.py 生成）
│   └── common.pri
├── client/                 客户端子项目
├── server/                 服务端子项目
├── docs/                   需求与设计文档
└── bin/                    编译输出（两端可执行文件）
```

## 编译与运行

```bash
# 编译（需要 Qt 6）
qmake6 FileTransferTool.pro
make -j4

# 运行（两个终端分别启动）
./bin/FileTransferServer     # 服务端：开始监听（默认端口 8888）
./bin/FileTransferClient     # 客户端：连接 127.0.0.1:8888
```

### 使用步骤

1. 启动服务端 → 点击"开始监听"（可在"服务设置"改端口和接收目录）
2. 启动客户端 → 在"连接设置"填 IP 和端口 → 点击"连接服务器"
3. 双方均可：点"选择文件发送"或直接把文件拖进窗口/拖拽区
4. 接收方日志显示进度，文件自动保存到设置目录（重名自动加 `(1)` 后缀）

## 测试要点

| 项目 | 方法 |
|---|---|
| 文本一致 | 传中文 .txt，`diff` 原文件与接收文件 |
| 图片完好 | 传 png/jpg/bmp，接收后正常打开 |
| 大文件/粘包 | 传 50MB+ 文件，进度条平滑推进，字节数一致 |
| 断线容错 | 传输中关闭对端，程序提示错误且不崩溃 |
| 重名处理 | 连传同名文件两次，第二份存为 `xxx(1).ext` |
